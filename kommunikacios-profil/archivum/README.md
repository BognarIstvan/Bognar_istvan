# Archívum: a profil korábbi változatai

Itt a kommunikációs profil korábbi, lezárt változatai vannak, változatlan szöveggel. Miért külön mappa: az élő profil egyetlen forrás (`../ROVID_PROFIL.md`), és minden Claude Code munkamenet csak azt tölti be; az archívumot semmi nem tölti be automatikusan, csak kézzel nyitható meg, hogy össze lehessen vetni, mi változott és miért.

| Mappa | Mi volt benne | Mikor váltotta le | Mi váltotta le |
| --- | --- | --- | --- |
| `1.0/` | az első profil (rövid és teljes változat, a hozzá tartozó CLAUDE.md), 2026-10-15-én összevonva | 2026-10-25 | 1.1: három tartóoszlop, ismert fogalmak listája, példák, származtatott változatok; a változások indoklása az élő `README.md` „Mi változott az 1.1-ben és miért” fejezetében |

Új archív mappa akkor készül, amikor egy következő változat leváltja az élőt: a leváltott fájlok változatlan másolata kerül ide, a számával nevezett mappába.
